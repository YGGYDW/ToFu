# ToFu - VPS 节点部署脚本

> **一键部署命令**（复制后粘贴至终端回车执行）：
> ```bash
curl -fL -o tofu.sh https://raw.githubusercontent.com/YGGYDW/ToFu/refs/heads/main/tofu.sh && bash tofu.sh
```

或使用管道方式执行：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/YGGYDW/ToFu/refs/heads/main/tofu.sh)
> ```
---

ToFu 是一个基于 [Xray-core](https://github.com/XTLS/Xray-core) 的多协议代理服务自动化部署与管理脚本，支持主流 Linux 发行版。通过统一的交互式命令行界面，自动化完成节点配置、防火墙放行、NAT 端口跳跃、SSL/TLS 证书申请、多协议分流及客户端自适应订阅分发。

---

## 快速概览

ToFu 集成了当前主流的、安全性最高的 3+1 套代理协议，在节点 3 的基础上额外加一套回源 CDN 节点，以适应各种网络状况：

| 节点类型 | 协议与流控组合 | 传输层 / 端口 | 认证与安全机制 | 主要适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **节点 1** | **VLESS + REALITY + Vision** | TCP / `443` | 借用大厂 TLS 证书特征，无需自带域名 | 日常低延迟直连，伪装度高 |
| **节点 2** | **Hysteria 2 (QUIC)** | UDP / `8443`<br>跳跃范围: `20000-50000` | 自签 ECC 证书 + SHA-256 指纹锁定，或 ACME 自动化证书 | 恶劣网络与高丢包环境，对抗单端口 QoS |
| **节点 3** | **VLESS + XHTTP + TLS** | TCP / `2053` | 自签 ECC 证书 + SHA-256 证书指纹锁定（支持绑定域名） | 分块流式传输，支持接入 Cloudflare CDN 回源 |
| **节点 4** | **VLESS + XHTTP (CDN 节点)** | TCP / `2053`（可选） | Cloudflare CDN 代理，可选接入 WARP 出站分流 | IP 或端口受限时的备用容灾通道，支持优选 IP |

原始安装只有 3 套节点，在设置 CDN 回源后后才产生第 4 套节点

利用节点 4 更换不同的优选 IP 或优选域名创建更多节点。

## 系统要求

### 操作系统与架构
* **操作系统**：
  * Debian 10 / 11 / 12
  * Ubuntu 20.04 / 22.04 / 24.04
  * CentOS / AlmaLinux / Rocky Linux 8 / 9
  * Alpine Linux 3.16+
* **CPU 架构**：
  * `amd64` (x86_64)
  * `arm64` (aarch64)
* **运行权限**：`root` 用户权限。

### 网络与防火墙要求
如果你的服务器位于 AWS、Google Cloud、阿里云、腾讯云、Oracle Cloud 等需要安全组（Security Group）的云平台上，请确保在云平台控制台开放以下端口：
* **TCP 80**：用于 ACME 证书申请与自动化续签（仅在使用自备域名时需要）。
* **TCP 443**：VLESS-REALITY 默认端口。
* **UDP 8443**：Hysteria 2 默认主监听端口。
* **UDP 20000-50000**：Hysteria 2 默认端口跳跃范围（可自定义）。
* **TCP 2053**：VLESS-XHTTP 默认端口（可作为 Cloudflare CDN 回源端口）。
* **TCP 50001-60000**：自适应订阅服务的随机监听端口。
  或者自定义以上端口

或使用管道方式执行：

## 协议与功能详解

### 1. VLESS + REALITY + XTLS-Vision (节点 1)
* **技术特点**：采用 XTLS Vision 流控，利用服务端在握手阶段伪装目标服务器（如 Apple CDN）的证书与 TLS 特征，无需用户自备域名，也不存在 CA 证书链审查风险。
* **多客户端兼容策略**：
  * 服务端将 `minClientVer` 显式设为 `0.0.0`，全面消除 Karing、Clash 等第三方非官方核心客户端连接时可能触发的 `reality verification failed` 握手阻断问题。
  * 针对 Clash Verge Rev / Clash MI 等 Mihomo 内核客户端，下发的配置中自动附带 `support-x25519mlkem768: true`，兼顾新旧客户端协商。

### 2. Hysteria 2 端口跳跃与双证书模式 (节点 2)
* **技术特点**：基于 QUIC 协议及 Brutal 拥塞控制算法，专为高丢包率、恶劣网络环境设计。
* **多端口跳跃机制**：
  * 默认在 Linux 内核通过 `iptables PREROUTING` 表建立 NAT 转发规则，将 UDP `20000-50000` 范围的所有请求转发至主端口 `8443`。
  * 客户端可配置多端口范围，自动在多个端口间切换，有效缓解运营商对单一 UDP 端口的速率限制（QoS）。
  * 脚本自带持久化规则管理（`/etc/tofu/iptables.sh`），服务器重启后自动恢复。
* **两种证书配置模式**：
  * **模式 1：无域名模式（自签证书 + pinSHA256 锁定）**
    * 无需购买或绑定域名。脚本自动生成 ECDSA P-256 自签证书，并计算提取其 SHA-256 证书指纹。
    * 客户端配置时通过固定证书指纹（`pinSHA256`）比对服务端身份，既免除了域名依赖，又杜绝了中间人欺骗风险。
    * *注意：v2rayN 用户若使用该模式，在编辑节点时请务必关闭【跳过证书验证 (AllowInsecure)】，以确保指纹比对生效。*
  * **模式 2：自备域名模式（ACME 自动化申请）**
    * 支持绑定自有域名，调用内置 `acme.sh` 向 Let's Encrypt 或 ZeroSSL 自动申请标准商业 SSL 证书。
    * 申请时需确保域名的 A/AAAA 记录已正确解析至该 VPS IP，并开放 TCP 80 端口；若使用 Cloudflare DNS 解析，解析记录需保持**灰色云朵**（仅 DNS 解析，不开启 CDN 代理）。
    * 证书签发后，脚本会自动注册 crontab 计划任务，到期前自动无感续签。

### 3. VLESS + XHTTP + TLS (节点 3)
* **技术特点**：使用 Xray-core 原生推出的 XHTTP（分块流式传输）协议，具备标准 HTTP 语义特征。
* **证书指纹与全生态自动填充**：
  * 采用自签 ECC 证书保护传输通道。
  * 导出的节点链接中同时包含 `pcs`、`pinnedPeerCertSha256` 以及 Shadowrocket 专用的 `hpkp` 参数。客户端（如 v2rayN、Shadowrocket 等）无论是通过订阅导入还是扫码导入，均会自动填充“证书 SHA-256”字段，开箱即连。

### 4. Cloudflare CDN 接入与 WARP 出站路由 (节点 4)
通过管理菜单的「Cloudflare CDN + WARP」专区，可将节点 3 扩展为具备 CDN 防护与回源能力的节点 4：
* **CDN 代理模式**：为节点 3 配置一个开启 Cloudflare 橙色云朵代理的子域名，流量先经 Cloudflare CDN 网络后再回源至 VPS。当 VPS 的 IP 或端口被阻断时，该模式可使服务快速恢复连通。
* **WARP 出站分流**：
  * 支持一键切换节点 3 / 节点 4 的出站网络通道为 Cloudflare WARP。
  * 开启后，客户端访问外部网站的出口 IP 将替换为 Cloudflare 节点 IP，隐藏 VPS 真实物理 IP，并可用于解锁流媒体等对原生机房 IP 受限的网站。

## 客户端自适应订阅服务

ToFu 内置了轻量级自适应订阅服务端，自动探测客户端适配的格式：

```text
客户端请求 (http://IP:PORT/sub/TOKEN)
                  │
                  ▼
       [ User-Agent 智能识别 ]
                  │
  ┌───────────────┼───────────────┐
  ▼               ▼               ▼
Clash / Mihomo  Karing   v2rayN / Shadowrocket
  │               │               │
  ▼               ▼               ▼
Clash YAML 配置   Sing-box JSON 配置  Base64 聚合节点链接
```

* **安全与访问控制**：
  * 订阅地址包含随机生成的 16 字节安全密钥（Token），防止未授权扫描探测。
  * 支持在管理菜单中一键重置 Token（旧链接立即失效）或修改监听端口。
* **客户端支持一览**：
  * **Windows**：v2rayN、Clash Verge Rev、Karing
  * **macOS**：Clash Verge Rev、Karing
  * **iOS**：Shadowrocket（小火箭）、Karing、V2box、Clash Mi
  * **Android**：v2rayNG、Karing
    不限于以上客户端

> [!NOTE]
> 原生官方 `sing-box` 客户端由于缺乏通用订阅的自动解析引擎，仅接受手工配置完整的 JSON 配置文件；如在 iOS / Android / 桌面端需要使用 sing-box 核心，建议优先使用基于 sing-box 开发且集成了订阅转换解析器的 **Karing** 客户端。

## 管理命令与菜单参考

### 快捷命令

ToFu 提供了直接通过命令行参数调用的快速管理指令：

| 命令 | 说明 |
| :--- | :--- |
| `tofu` | 打开交互式图形主管理菜单 |
| `tofu info` | 查看所有节点明细、直连链接、自适应订阅地址与二维码 |
| `tofu sub` | 打开订阅服务管理设置（重置 Token、换端口、启停订阅） |
| `tofu port` | 节点端口修改（Reality、Hy2 主端口/跳跃范围、XHTTP 端口） |
| `tofu doctor` | 运行状态诊断程序（进程、端口、NAT 转发、证书有效期检测） |
| `tofu cdn` | 快捷进入 Cloudflare CDN 接入与 WARP 出站管理专区 |
| `tofu kernel` 或 `tofu update` | 打开 Xray 内核管理与版本切换菜单 |
| `tofu restart` | 平滑重启 ToFu 主服务与订阅服务 |
| `tofu start` | 启动 ToFu 服务 |
| `tofu stop` | 停止 ToFu 服务 |
| `tofu uninstall` | 完整卸载 ToFu 服务及相关配置 |

### Xray 内核版本管理与切换

在主管理菜单中输入 `5`（或命令行执行 `tofu kernel`），可进入内核管理与版本切换页面：

```text
========================================================================
                         Xray 内核管理与切换                    
   当前内核版本 : v26.6.27
========================================================================

  1. 升级 Xray-core 至最新版 【有更新】

  2. Xray v26.6.27（黄金稳定版）

  0. 返回主菜单

------------------------------------------------------------------------
请输入操作序号 [1-3]: 
```

* **1. 升级 Xray-core 至最新版**：实时查询 GitHub XTLS/Xray-core 仓库的最新发布版本并拉取更新。
* **2. Xray v26.6.27（黄金稳定版）**：采此版本的握手标准能有效避免最新激进版本在部分端客户端（如 Shadowrocket、旧版第三方内核）引发的抗量子握手校验不兼容问题。
* **故障回滚**：升级或版本切换过程中，脚本会自动创建旧核心的二进制备份；替换完成后会自动执行语法测试，验证成功后方才重启服务；若检测失败或启动异常，将在毫秒级内自动还原旧核心，确保服务不中断。

## 诊断与故障排除

### 系统自检程序 (`tofu doctor`)
如果在连接或使用过程中遇到异常，可在终端运行 `tofu doctor` 执行一键诊断，自检工具将按顺序输出以下状态：
1. **进程状态**：检查 Xray-core 与订阅服务进程是否存在及 PID；
2. **端口监听**：使用 `ss` 或 `netstat` 检测 443、8443、2053 及订阅端口的实际监听状态；
3. **防火墙与 NAT**：检测 iptables `PREROUTING` 链中端口跳跃规则与系统转发参数（`net.ipv4.ip_forward`）；
4. **证书状态**：检测 ECC 自签证书或 ACME 域名证书的到期剩余天数；
5. **系统负载与内存**：输出当前系统资源占用情况。

### 关键路径与文件说明
* 配置根目录：`/etc/tofu/`
* 主配置文件：`/etc/tofu/config.json`
* 环境变量与状态文件：`/etc/tofu/node_info.env`
* 节点明细导出文件：`/etc/tofu/nodes.txt`
* 端口跳跃持久化脚本：`/etc/tofu/iptables.sh`
* 主服务单元：`/etc/systemd/system/tofu.service`
* 订阅服务单元：`/etc/systemd/system/tofu-sub.service`

## 卸载

若需从服务器彻底移除 ToFu：
1. 在终端执行 `tofu` 进入管理菜单，输入 `9`（完整卸载 ToFu 组件）；
2. 或在命令行直接执行：
   ```bash
   tofu uninstall
   ```
卸载过程将自动停止并注销 systemd 服务、清除所有配置文件与安装目录（`/etc/tofu/`）、撤销 iptables 端口跳跃与转发规则，并恢复系统依赖记录。
