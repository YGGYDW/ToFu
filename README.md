为了保证无论在什么网络封锁与拥堵环境下都能正常上网，本部署精炼设计了以下三套各司其职的协议组合：

| 节点类型 | 协议架构组合 | 默认端口 (支持自定义) | 核心定位与使用场景 | 推荐客户端内核 |
| :---: | :---: | :---: | :--- | :---: |
| 🥇 **节点 1** | **`VLESS + REALITY + XTLS-Vision`** | `443` (TCP) | **【主力节点】** 不需要注册域名、自签证书；借用大厂真实 TLS 握手特征；Linux 内核零拷贝拼接明文流，CPU 占用接近 0，抗主动探测顶尖水平。 |
| 🥈 **节点 2** | **`Hysteria 2 (UDP 端口跳跃)`** | `8443` (主)<br>`20000:50000` (跳跃) | **【暴力带宽】** 魔改 QUIC 协议 + Brutal 拥塞控制；在晚高峰跨国出口拥堵、丢包率达 30%~50% 时依然能跑满带宽；内核级 20001 个端口跳跃彻底突破运营商 UDP 限速。 |<br>[sing-box(客户端) |
| 🥉 **节点 3** | **`VLESS + XHTTP + TLS`** | `2053` (TCP) | **【多样化DIY】** 采用分块流式传输；如果 VPS IP 被墙，打开小黄云套上 Cloudflare CDN 即可起死回生！支持切换 100% Cloudflare WARP 出站。 |

### 🌐 节点 3 专属功能：Cloudflare CDN + WARP 出入双模式解析

在 ToFu 管理菜单中，节点 3 提供了独立的可视化分流切换专区，两种模式随心切：
* **模式 A【原生直连出口】（速度优先 · 推荐日常）**：入口走 Cloudflare 防护保护 VPS，出口由 VPS 物理网卡直连访问目标网站。速度快、延迟低。
* **模式 B【Cloudflare WARP 100% 闭环出站】**：出站通过官方 WARP 代理转发。目标网站检测到的 IP 100% 显示为 Cloudflare 官方 IP，实现前后两端彻底隐藏真实 VPS。
*(注：该分流切换仅影响节点 3，节点 1 与节点 2 永远保持原生直连极速架构)*

### ✅ 小黑板

### 什么是套 CDN？

套 CDN 就是在你的电脑和 VPS 服务器之间加一层 CDN 代理，让你的电脑不再直接连接 VPS 的真实 IP，而是先连接 CDN，再由 CDN 将流量转发到 VPS，这需要注册一个域名，一级二级域名无所谓，但得有。

例如，你电脑上的 v2rayN 连接 VPS，这个过程对于 VPS 上的代理服务来说，就属于入站（Inbound）。套上 CDN 后，你的网络连接会先经过 CDN 节点，网络运营商和 GFW 只能看到你连接了 CDN 的 IP，而不是直接看到 VPS 的真实 IP，这样就降低了 VPS 真实 IP 暴露的风险。

套 CDN 的用途，就是在 VPS 的 IP 被封锁时，通过 CDN 连接服务器。

套 CDN 可能会增加网络延迟，因为数据需要经过 CDN 节点中转。但通过更换优选IP或域名可以改善延迟。

### 什么是 WARP？

WARP 是从你的 VPS 访问目标网站时通过 Cloudflare 的网络转发，而不是直接使用 VPS 原本的公网出口

例如，你需要你的 vp s访问 Google ，开启 WARP 后， vps 会先经过 Cloudflare ，由 Cloudflare 再去访问 Google ，到检测 IP 的网站你会发现， IP 是 Cloudflare 的，而不是 vps 的。

### 总结一下

* **CDN 入站（lnbound）：** 你的电脑（v2rayN）连接到 vps 的过程。
* **WARP 出站（Outbound）：** vps 帮你去访问目标网站（例如Google）的过程。

✅ 搞清楚这个，再决定是否套 CDN 和开启 WARP 。

## 三、 客户端配置与使用指南

安装完成后，节点配置信息已自动保存在 `/etc/tofu/nodes.txt`。运行 `tofu info` 即可查看各个节点的直连链接与二维码。

各主流平台的具体导入与使用方式如下：

### 1. Windows 平台：v2rayN
* **推荐核心**：建议使用最新版 v2rayN。
* **快速导入方式**：
  * **剪贴板一键导入**：在终端复制节点的 `vless://` 或 `hysteria2://` 链接，在 v2rayN 主界面直接按下快捷键 `Ctrl + V` 即可自动识别并添加节点。
  * **屏幕二维码扫描**：在终端通过 `tofu info` 调出二维码，在 v2rayN 菜单中点击「服务器」->「扫描屏幕上的二维码」导入。
* **各协议使用说明**：
  * **节点 1 (REALITY) & 节点 3 (XHTTP)**：原生完美支持，直接设为活动服务器即可极速畅联。
  * **节点 2 (Hysteria 2 端口跳跃)**：右键编辑该节点，在右上角空白处点击，将核心类型切换为 `sing-box`，否则真连接延迟为-1。

---

### 2. iOS 平台：Shadowrocket (小火箭)
* **快速导入方式**：
  * **自动识别添加**：复制终端中的任意节点链接，打开 Shadowrocket 时应用会自动弹窗提示「检测到剪贴板中的节点，是否添加？」，点击保存即可。
  * **扫码添加**：点击 Shadowrocket 首页左上角的「扫码」图标，直接对准 VPS 终端打印的二维码进行扫描。
* **协议兼容性与设置**：
  * Shadowrocket 最新版已原生全面兼容三大节点协议：
    * 节点 1 (VLESS-REALITY-Vision) 完美握手；
    * 节点 2 (Hysteria 2) 原生支持端口跳跃参数（URL 中已包含 `ports=20000-50000`，无需任何二次手工修改）；
    * 节点 3 (VLESS-XHTTP) 原生兼容。
  * 建议将首页「全局路由」设置为 **「配置 (Config)」**，实现访问国内应用走直连、海外应用智能走代理分流。

---

### 3. Android 平台：v2rayNG / sing-box
* **v2rayNG**：点击右上角 `+` 号，选择「从剪贴板导入」或「扫描二维码」快速导入节点 1 与节点 3；
* **sing-box for Android**：完美支持节点 2 (Hysteria 2) 及其动态端口跳跃特性。

---

### 4. macOS 平台：v2rayU / Clash Verge Rev / sing-box
* 使用方式与 Windows 类似，支持剪贴板 `vless://` / `hysteria2://` 快捷导入。

## 四、 云服务商安全组 / 防火墙开放端口提示

如果你使用的是主流云服务商（如 **AWS、甲骨文 Oracle、谷歌云 GCP、腾讯云/阿里云国际、Hetzner、搬瓦工、Linode、DigitalOcean** 等），务必在云服务器后台网页控制台的 **“安全组 / 防火墙（Security Group / Firewall）”** 中开放以下端口规则（**如果你在安装时选择了自定义模式修改了端口，请对应开放你所自定义的端口**）：

| 端口号 | 协议类型 | 对应协议用途 | 重要程度 |
| :---: | :---: | :--- | :---: |
| **`443`**（或自定义） | **TCP** | 节点 1：VLESS + REALITY + XTLS-Vision 主力直连端口 | 必开 |
| **`8443`**（或自定义） | **UDP** | 节点 2：Hysteria 2 主监听端口 | 必开 |
| **`20000 ~ 50000`**（或自定义） | **UDP** | 节点 2：Hysteria 2 内核级 NAT 端口跳跃转发范围 (共 20001 个端口) | 必开 (抗QoS核心) |
| **`2053`**（或自定义） | **TCP** | 节点 3：VLESS + XHTTP + TLS 容灾防封 / CDN 回源端口 | 必开 |

> 📌 **贴心提示**：
> 1. **是否支持自定义端口？** **完全支持！** 在运行脚本安装或重置时选择「模式 2 (自定义参数模式)」，即可自由设定各个节点的监听端口与跳跃端口范围。如果在自定义模式中修改了默认端口，请务必在云后台安全组中同步放行你所指定的自定义端口。
> 2. 如果你的 VPS 是没有外部网页安全组拦截的机器（纯 Linux 系统内部防火墙），脚本内置的自检程序会全自动通过完成端口放行，**无需你进行任何手动操作**。
> 3. 脚本在运行时会对常用端口进行自动化状态扫描：
>    * 终端显示为 **`[✔ 绿色]`**：代表端口空闲通畅，可正常使用；
>    * 终端显示为 **`[✖ 红色]`**：代表端口被系统其他程序占用或关闭，脚本会自动为你避开冲突端口。
